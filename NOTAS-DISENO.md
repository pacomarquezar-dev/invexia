# Notas de diseño

- Calculadora FIRE: el dato de "años para alcanzarlo" debería tener más protagonismo visual que el "número FIRE" en sí — es el resultado más impactante para el usuario y actualmente pasa desapercibido.
- Revisar el nombre "número FIRE" — es una jerga poco conocida y poco atractiva para el público objetivo (gente joven que empieza en finanzas). Buscar un nombre más descriptivo relacionado con jubilación/independencia financiera antes del lanzamiento.
- Gráficos de las calculadoras: ya rediseñados los de evolución con línea (`YearlyCapitalChart`, usado en interés compuesto/FIRE/objetivo de ahorro) y los donut de composición (los 4). Pendiente de pasar por el mismo rediseño: `FeeImpactChart` (coste de comisiones), `DcaVsLumpSumChart` (DCA vs pago único) e `InflationImpactChart` (inflación) — siguen con los colores/estilo neutros originales porque no encajan en el patrón "crecimiento con interés vs. sin invertir" ya resuelto.
- `InflationImpactChart` (calculadora de inflación): la etiqueta de la `ReferenceLine` ("Valor nominal (sin inflación)") se solapa visualmente con el primer tick del eje Y — defecto preexistente, no introducido en los rediseños de gráficos recientes, pendiente de corregir cuando se rediseñe ese gráfico.
- Pantalla de resultado del test de perfil: darle identidad visual propia por perfil (color/icono distinto para Conservador/Moderado/Agresivo) y personalizar el texto según respuestas concretas, no solo la categoría general. Explorar una versión "tarjeta para compartir" pensada para redes sociales, al estilo de un resultado de test de personalidad. Sin estadísticas comparativas entre usuarios (no hay base de datos).
- El rate limiting del chatbot (20 mensajes/24h) es en memoria, por instancia del servidor — no un límite global exacto si Vercel escala a varias instancias. Suficiente para tráfico bajo actual. Si el tráfico crece, migrar a un límite distribuido real (ej. Vercel KV / Upstash Redis) para que el límite sea exacto entre instancias.
- Botón del widget de chat: rediseñado con identidad propia — morado (`accent-secondary`) en vez del verde del resto de la web, burbuja de conversación como icono y un pulso sutil (`animate-chat-pulse`) para que se note que es interactivo. Idea pendiente y de menor prioridad: añadir una etiqueta de texto tipo "¿Dudas?" junto al botón.
- Página 404 (`app/not-found.tsx`): implementada de forma funcional con el mismo estilo neutro que el resto del sitio (mensaje + enlace de vuelta al inicio), pero sin trabajo de diseño propio todavía — pendiente de darle más identidad visual (ilustración, icono o composición distinta a una página de contenido normal) en la fase de diseño.
