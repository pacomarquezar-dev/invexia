# Notas de diseño

- Calculadora FIRE: el dato de "años para alcanzarlo" debería tener más protagonismo visual que el "número FIRE" en sí — es el resultado más impactante para el usuario y actualmente pasa desapercibido.
- Revisar el nombre "número FIRE" — es una jerga poco conocida y poco atractiva para el público objetivo (gente joven que empieza en finanzas). Buscar un nombre más descriptivo relacionado con jubilación/independencia financiera antes del lanzamiento.
- Los gráficos de las calculadoras funcionan bien mecánicamente pero visualmente son poco atractivos — pendiente de mejorar en la fase de diseño con referencias.
